# 常见机器学习算法

**标签**: 机器学习, 算法

机器学习按学习方式大致分为：**监督学习**、**无监督学习**、**半监督学习**、**强化学习**。下面按任务类型梳理高频算法。

---

## 一、监督学习（Supervised Learning）

有标签数据，学习「输入 → 输出」的映射。

### 1. 分类算法（Classification）

| 算法 | 核心思想 | 适用场景 | 优缺点简述 |
|------|----------|----------|------------|
| 逻辑回归 Logistic Regression | 用 sigmoid 把线性结果映射成概率 | 二分类、基线模型 | 简单可解释；难拟合复杂非线性 |
| K 近邻 KNN | 看最近 K 个样本的多数类别 | 小数据、简单分类 | 直观；预测慢、对尺度敏感 |
| 决策树 Decision Tree | 按特征阈值递归划分 | 可解释业务规则 | 易理解；易过拟合 |
| 随机森林 Random Forest | 多棵树投票/平均 | 表格数据通用强基线 | 效果稳；模型较大 |
| GBDT / XGBoost / LightGBM / CatBoost | 梯度提升树，逐步纠正残差 | 竞赛与工业表格数据首选 | 精度高；调参相对复杂 |
| 支持向量机 SVM | 找最大间隔超平面 | 中小规模、高维数据 | 间隔大泛化好；大样本慢 |
| 朴素贝叶斯 Naive Bayes | 条件独立假设下的贝叶斯分类 | 文本分类、垃圾邮件 | 训练快；特征独立假设偏强 |
| 神经网络 MLP | 多层非线性变换 | 复杂模式、特征交互多 | 表达能力强；需更多数据与调参 |

### 2. 回归算法（Regression）

| 算法 | 核心思想 | 适用场景 |
|------|----------|----------|
| 线性回归 Linear Regression | 拟合线性关系，最小化平方误差 | 连续值预测基线 |
| 岭回归 Ridge / Lasso / Elastic Net | 加 L2/L1 正则防过拟合、做特征选择 | 特征多、共线性 |
| 决策树 / 随机森林回归 | 用树结构预测连续值 | 非线性、异方差 |
| XGBoost / LightGBM 回归 | 提升树回归 | 表格回归任务主流 |
| 支持向量回归 SVR | SVM 思想用于回归 | 中小规模非线性回归 |

## 二、无监督学习（Unsupervised Learning）

无标签，发现数据内在结构。

### 1. 聚类（Clustering）

| 算法 | 核心思想 | 适用场景 |
|------|----------|----------|
| K-Means | 最小化簇内平方距离，需指定 K | 球形簇、大数据 |
| 层次聚类 Hierarchical | 自底向上/自顶向下合并或分裂 | 需要树状结构、样本量不大 |
| DBSCAN | 基于密度，可发现任意形状簇并识别噪声 | 噪声多、簇形状不规则 |
| 高斯混合模型 GMM | 假设数据由多个高斯分布混合 | 软聚类、概率归属 |

### 2. 降维（Dimensionality Reduction）

| 算法 | 核心思想 | 适用场景 |
|------|----------|----------|
| PCA 主成分分析 | 找方差最大的正交方向 | 可视化、去噪、压缩 |
| t-SNE | 保持局部邻域的非线性嵌入 | 二维/三维可视化 |
| UMAP | 流形学习，通常比 t-SNE 更快 | 可视化与下游特征 |
| 自编码器 Autoencoder | 神经网络压缩再重构 | 非线性降维、异常检测 |

### 3. 关联规则 / 异常检测

- **Apriori / FP-Growth**：购物篮分析，挖掘频繁项集与关联规则。
- **Isolation Forest / LOF**：异常点检测，用于风控、运维告警。

## 三、集成学习（Ensemble Learning）

把多个弱学习器组合成强模型。

| 方法 | 思路 | 代表 |
|------|------|------|
| Bagging | 并行采样训练，降低方差 | 随机森林 |
| Boosting | 串行关注难样本，降低偏差 | AdaBoost、GBDT、XGBoost、LightGBM |
| Stacking | 用元模型融合多个基模型输出 | 竞赛中常见 |

## 四、深度学习相关常用模型

严格说深度学习是机器学习子集，工业中极常见：

| 方向 | 代表模型 | 典型用途 |
|------|----------|----------|
| 图像 | CNN、ResNet、YOLO | 分类、检测、分割 |
| 序列 / 文本 | RNN、LSTM、Transformer | 翻译、情感、生成 |
| 推荐 / 表格 | Wide&Deep、DNN、Transformer 变体 | CTR、排序 |
| 生成 | GAN、VAE、Diffusion | 图像/内容生成 |
| 大模型 | GPT、BERT 及各类 LLM | NLP、Agent、RAG |

## 五、强化学习（Reinforcement Learning）

通过与环境交互、最大化累积奖励来学习策略。

| 算法 | 类型 | 说明 |
|------|------|------|
| Q-Learning / DQN | 基于价值 | 离散动作常用 |
| Policy Gradient / A2C / PPO | 基于策略 | 连续控制更稳 |
| Actor-Critic | 价值+策略 | 现代深度强化学习主流框架 |

---

## 六、怎么选算法（实用经验）

1. **表格数据**：先试 LightGBM / XGBoost / 随机森林；需要解释性再用线性模型或单棵树。
2. **文本**：传统可用 TF-IDF + 朴素贝叶斯/逻辑回归；现代优先预训练 Transformer / LLM。
3. **图像**：优先 CNN / Vision Transformer 预训练微调。
4. **小样本**：优先简单模型 + 正则；谨慎用很深的网络。
5. **需要可解释**：线性模型、决策树、SHAP 解释树模型。
6. **聚类未知形状**：优先 DBSCAN / GMM，而不是死用 K-Means。

## 七、常见评估指标速查

### 分类
- 准确率 Accuracy、精确率 Precision、召回率 Recall、F1
- ROC-AUC、PR-AUC（类别不平衡更看后者）

### 回归
- MAE、MSE/RMSE、R²、MAPE

### 聚类
- 轮廓系数 Silhouette、DB Index；有标签时可用 ARI / NMI

### 排序 / 推荐
- AUC、NDCG、Recall@K、MAP
