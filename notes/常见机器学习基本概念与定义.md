# 常见机器学习基本概念与定义

**标签**: 机器学习, 概念

机器学习是让计算机从数据中自动学习规律，并用于预测或决策的方法。本文整理高频**概念与定义**，便于复习与笔记检索。

---

## 一、学习范式（Learning Paradigms）

| 概念 | 英文 | 定义 |
|------|------|------|
| 机器学习 | Machine Learning | 从数据中学习模式，使系统在未见过的数据上也能表现良好 |
| 监督学习 | Supervised Learning | 有输入与标签，学习映射关系 \(f(x) \rightarrow y\) |
| 无监督学习 | Unsupervised Learning | 无标签，发现数据的结构、分组或表示 |
| 半监督学习 | Semi-supervised Learning | 少量有标签 + 大量无标签，结合两者训练 |
| 强化学习 | Reinforcement Learning | 智能体与环境交互，通过奖励信号学习最优策略 |
| 自监督学习 | Self-supervised Learning | 从数据自身构造伪标签（如遮挡预测），常见于预训练 |
| 迁移学习 | Transfer Learning | 把在一个任务上学到的知识迁移到另一个相关任务 |
| 在线学习 | Online Learning | 数据流式到达，模型持续增量更新 |
| 批量学习 | Batch Learning | 用完整训练集一次性（或分批）训练模型 |

---

## 二、数据与特征（Data & Features）

| 概念 | 英文 | 定义 |
|------|------|------|
| 样本 / 实例 | Sample / Instance | 一条观测数据，通常对应特征空间中的一个点 |
| 特征 | Feature | 描述样本的属性或输入变量，也称自变量 |
| 标签 / 目标 | Label / Target | 监督学习要预测的输出，也称因变量 |
| 训练集 | Training Set | 用于拟合模型参数的数据 |
| 验证集 | Validation Set | 用于调超参数、做模型选择的数据 |
| 测试集 | Test Set | 仅用于最终评估泛化能力，训练中不可使用 |
| 特征工程 | Feature Engineering | 设计、变换、选择特征以提升模型效果 |
| 特征缩放 | Feature Scaling | 如标准化、归一化，使不同量纲特征可比 |
| 独热编码 | One-Hot Encoding | 把类别特征转为 0/1 向量 |
| 缺失值 | Missing Value | 数据中未观测到的字段，需删除、填充或建模处理 |
| 异常值 | Outlier | 明显偏离多数分布的点，可能是噪声或关键事件 |
| 类别不平衡 | Class Imbalance | 不同类别样本数量差异大，影响指标与决策阈值 |

---

## 三、模型与学习过程（Model & Training）

| 概念 | 英文 | 定义 |
|------|------|------|
| 模型 | Model | 对数据生成机制的假设形式，含可学习参数 |
| 参数 | Parameter | 由训练数据估计得到的量（如权重 \(w\)） |
| 超参数 | Hyperparameter | 训练前设定、不能由普通训练直接学出的量（如学习率、树深度） |
| 假设空间 | Hypothesis Space | 模型可能表示的所有函数集合 |
| 损失函数 | Loss Function | 衡量单条（或一批）预测与真实值差距的函数 |
| 代价 / 目标函数 | Cost / Objective | 在全部或一批样本上汇总后的优化目标 |
| 优化器 | Optimizer | 最小化损失的算法，如 SGD、Adam |
| 梯度下降 | Gradient Descent | 沿损失函数梯度反方向更新参数 |
| 学习率 | Learning Rate | 每次参数更新的步长 |
| 批次 / 批量大小 | Batch / Batch Size | 一次参数更新所用的样本数 |
| 轮次 | Epoch | 完整遍历训练集一次称为一个 epoch |
| 前向传播 | Forward Pass | 输入经模型计算得到预测 |
| 反向传播 | Backpropagation | 用链式法则从输出端回传梯度以更新参数 |
| 收敛 | Convergence | 训练过程中损失趋于稳定、参数更新变小 |

## 四、偏差、方差与泛化（Bias-Variance & Generalization）

| 概念 | 英文 | 定义 |
|------|------|------|
| 泛化 | Generalization | 模型在未见数据上的表现能力 |
| 过拟合 | Overfitting | 训练集很好、测试集很差，记住了噪声 |
| 欠拟合 | Underfitting | 训练与测试都差，模型能力不足或训练不够 |
| 偏差 | Bias | 模型假设过简导致的系统性误差 |
| 方差 | Variance | 模型对训练数据波动过于敏感导致的误差 |
| 偏差-方差权衡 | Bias-Variance Tradeoff | 降低偏差常增方差，反之亦然，需折中 |
| 正则化 | Regularization | 约束模型复杂度（如 L1/L2、Dropout、早停）以减轻过拟合 |
| 早停 | Early Stopping | 验证集表现不再提升时停止训练 |
| 交叉验证 | Cross Validation | 如 K 折，轮流用不同子集验证，更稳健地评估 |
| 奥卡姆剃刀 | Occam's Razor | 在同等效果下优先选更简单的模型 |

## 五、任务类型（Problem Types）

| 概念 | 英文 | 定义 |
|------|------|------|
| 分类 | Classification | 预测离散类别（二分类 / 多分类 / 多标签） |
| 回归 | Regression | 预测连续数值 |
| 聚类 | Clustering | 将相似样本分到同一组，无预设标签 |
| 降维 | Dimensionality Reduction | 用更少维度保留主要信息 |
| 排序 | Ranking | 学习样本相对顺序（搜索、推荐） |
| 生成 | Generation | 学习数据分布并生成新样本 |
| 密度估计 | Density Estimation | 估计数据的概率分布 |
| 异常检测 | Anomaly Detection | 识别不符合常态模式的样本 |

## 六、评估指标相关概念（Evaluation）

| 概念 | 英文 | 定义 |
|------|------|------|
| 准确率 | Accuracy | 预测正确数 / 总样本数 |
| 精确率 | Precision | 预测为正的样本中真正为正的比例 |
| 召回率 | Recall | 所有真正为正的样本中被找出的比例 |
| F1 分数 | F1 Score | 精确率与召回率的调和平均 |
| 混淆矩阵 | Confusion Matrix | 统计 TP/FP/TN/FN 的表格 |
| ROC 曲线 | ROC Curve | 不同阈值下 TPR 对 FPR 的曲线 |
| AUC | AUC | ROC 曲线下面积，衡量排序区分能力 |
| MAE | Mean Absolute Error | 绝对误差平均，回归常用 |
| MSE / RMSE | Mean Squared Error | 平方误差（及其开方），对大误差更敏感 |
| R² | Coefficient of Determination | 模型解释目标方差的比例 |
| 基线 | Baseline | 简单对照模型，用来判断改进是否有意义 |

## 七、概率与统计基础概念（Probability Basics）

| 概念 | 英文 | 定义 |
|------|------|------|
| 先验 | Prior | 见到数据前对参数/类别的信念 |
| 后验 | Posterior | 见到数据后更新的信念 |
| 似然 | Likelihood | 在给定参数下观测到当前数据的可能性 |
| 最大似然估计 MLE | Maximum Likelihood Estimation | 选使数据出现概率最大的参数 |
| 最大后验 MAP | Maximum A Posteriori | 在先验约束下最大化后验 |
| 期望 | Expectation | 随机变量的平均值 |
| 方差 / 协方差 | Variance / Covariance | 刻画波动及变量间线性相关 |
| 独立同分布 i.i.d. | Independent and Identically Distributed | 样本相互独立且来自同一分布的常见假设 |

## 八、神经网络常用概念（Neural Network Basics）

| 概念 | 英文 | 定义 |
|------|------|------|
| 神经元 | Neuron | 接收输入、加权求和再经激活的计算单元 |
| 激活函数 | Activation Function | 引入非线性，如 ReLU、Sigmoid、Softmax |
| 层 | Layer | 一组神经元的组织结构（输入层/隐藏层/输出层） |
| 权重与偏置 | Weights & Bias | 连接强度与偏移项 |
| 嵌入 | Embedding | 把离散对象（词、ID）映射为稠密向量 |
| 注意力 | Attention | 按相关性对输入加权聚合信息 |
| Transformer | Transformer | 以自注意力为核心的序列建模架构 |
| 预训练 | Pretraining | 在大规模数据上先学通用表示 |
| 微调 | Fine-tuning | 在下游任务数据上继续训练适配 |
| Dropout | Dropout | 训练时随机丢弃单元，减轻过拟合 |

## 九、工程与流水线概念（ML Pipeline）

| 概念 | 英文 | 定义 |
|------|------|------|
| 数据泄漏 | Data Leakage | 训练时误用了测试时不可得的信息，导致虚高分数 |
| 流水线 | Pipeline | 预处理 → 训练 → 评估 → 部署的固定流程 |
| 推理 / 预测 | Inference | 用已训练模型对新样本出结果 |
| 在线推理 | Online Inference | 实时单条/小批预测 |
| 批处理推理 | Batch Inference | 定时对大批数据离线打分 |
| 模型监控 | Model Monitoring | 跟踪线上效果、数据漂移与延迟 |
| 数据漂移 | Data Drift | 线上数据分布相对训练数据发生变化 |
| 概念漂移 | Concept Drift | 输入与标签的关系随时间变化 |

## 十一、易混概念对比

| 对比 | 区别要点 |
|------|----------|
| 参数 vs 超参数 | 参数靠训练学；超参数靠人工/搜索设定 |
| 训练集 vs 验证集 vs 测试集 | 拟合 / 选模 / 最终报告，职责分离 |
| 过拟合 vs 欠拟合 | 太复杂记噪声 vs 太简单学不够 |
| 精确率 vs 召回率 | 查得准 vs 查得全，常需权衡 |
| 标准化 vs 归一化 | 常指 z-score 与缩放到 \[0,1\]，目的都是尺度对齐 |
| 监督学习 vs 自监督 | 外部标签 vs 从数据自构标签 |
| 偏差 vs 方差 | 模型系统性偏离 vs 对数据扰动敏感 |
